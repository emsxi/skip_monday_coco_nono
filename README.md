# 跳过周一 ✨ Skip Monday

> 周深陪你撑过去 💙 风雨同周，深情不移

一个以周深为主题的 PWA 小应用，IP 角色「可可 CoCo」和「嫑嫑 NoNo」陪你度过每一个不想上班的日子。

## ✨ 功能

### 🔘 一键跳过
- 大按钮一键「跳过周一」，触发日历撕碎动画
- 4种销毁特效：粉碎、爆碎、火箭升空、旋转冲走
- 粒子特效 + 触感振动反馈
- 累计跳过次数记录

### 🎵 周深语录 & 歌曲
- 100+ 条周深/可可/嫑嫑语录，随机展示
- 113 首歌曲推荐，附 QQ 音乐 & 网易云直达链接
- 200 条趣味整活建议

### 📸 分享卡片
- 一键生成精美语录卡片图片
- 可保存分享

### 📱 PWA 支持
- Service Worker 离线缓存
- 支持添加到主屏幕
- 独立应用模式体验

### 🔧 内容管理
- admin.html 管理后台
- 支持增删语录、建议、歌曲
- 搜索功能
- 数据导入/导出

### 🎨 视觉体验
- 深色太空主题 UI（星空闪烁背景）
- 可可 & 嫑嫑 SVG 原创形象
- 适配每日不同文案（周一特别关怀、周四冲刺鼓励等）

## 🔄 自动更新

- GitHub Actions 每周自动验证和更新 QQ 音乐歌曲链接

## 🛠️ 技术栈

- 纯前端单 HTML + data.json
- PWA (manifest.json + sw.js)
- html2canvas 生成分享图
- localStorage 持久化
- QQ 音乐 API 歌曲链接验证

## 📦 文件结构

```
├── index.html      # 主页面
├── admin.html      # 管理后台
├── data.json       # 内容数据（语录/建议/歌曲/动画）
├── manifest.json   # PWA 配置
├── sw.js           # Service Worker
├── update_songs.js # 歌曲链接更新脚本
└── images/         # SVG 角色图片
```
